# SpendWise – Personal Budget & Expense Tracker

SpendWise is a simple personal budget and expense tracker built with **HTML and CSS**. The project helps users organize their expenses and demonstrates the use of tables, forms, multimedia, interactive HTML elements, and advanced CSS selectors.

## Features

* Add expense information using a form
* Select an expense category from a dropdown
* View expenses in a structured table
* Display sample expense records
* Embedded budgeting video
* Budget tracker logo/image
* Collapsible instructions using `<details>` and `<summary>`
* Hover effects on expense table rows
* Focus effects on form inputs
* Styled and organized user interface

## Technologies Used

* HTML5
* CSS3
